звуки окружения
в папке amb(тут будут звуки окружения) запускать в начале сцен
green = зеленый уровень +
sand = пустнный уровень +
stone = каменный уровень  +

абилки папка ability (тут будут звуки абилок)
ability_artillery_fly = запускать когда ракета полетела  +
ability_artillery_request = запускать когда ткнул/выбрал абилку артилерий +

ability_healing = запускать когда подхилился +

ability_meteor_rain_earthquake = запускать когда трясется экран во время метеоритного дождя(это луп) +
ability_meteor_rain_explosion-001-004 = запускать когда метеорит упал на землю(рандомно воспроизводил один из 4 звуков) +

ability_mine_set = запускать когда поставил мину +

ability_money_maker = запускать когда прибавились бабосики +


папка enemy (тут будут звуки касаеющиеся врагов)
enemy_die-001-004 = нужно вызывать когда враг убит

папка sfx other(тут звуки разные, но пока ток звук взрыва) 
explosion-001-004 = запускать на любые виды взрыва в игре, кроме метеоритного дождя

папка tower sounds(тут будут все звуки связанные с башнями)
10dollar_tower_shoot-001 - 004 = когда башня стреляет(рандомно выьбирать один из 4 звуков при каждом выстреле)
20dollar_tower_shoot-001 - 004 = когда башня стреляет(рандомно выьбирать один из 4 звуков при каждом выстреле)
freezergun_tower_shoot_loop = когда пушка холода жгет запускать(это луп)
lasergun_tower_shoot_loop = когда лазерная пушка стреляет(это тоже луп)
rocket_launcher_tower_shoot-001 - 004 = когда башня стреляет(рандомно выьбирать один из 4 звуков при каждом выстреле)
tower_builded = когда башня построилась
tower_damaged-001 - 004 = когда башне наносят урон (рандомно выьбирать один из 4 звуков при каждом попаданий)
tower_destroyed-001 - 004 = когда башня разрушена (выбирать рандомно один из 4 звуков)

папка ui (тут будут звуки ui естесна)
ui_accept = кнопка принять или выбрать чтото либо подтвердить
ui_back = кнопка назад или отмена
ui_click = (лучше обясню словестно)
ui_life_damage = когда получаешь дамаг (когда моб проскочил) 
ui_lose = когда проиграл раунд
ui_money = когда потратил или заработал деняк
ui_popup_shop = когда открываешь магазин или какие то другие окна что вылезают поверх игры
ui_win = когда победил раунд
